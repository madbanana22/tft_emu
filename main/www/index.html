Test generator (GPIO loopback)
Two drive modes. Jumpered: wire test pins to emulator pins (SCK, MOSI, CS, DC, RES) and start. Internal loopback: no wiring — the internal master drives the emulator GPIO pads directly, so the real SPI slave path is exercised without jumpers. Use loopback to check the emulator when the jumpered mode stays black.

Code interface (no GPIO)
Drive the panel from code: POST /api/inject with raw bytes as body — first 11 bytes typically the window command (2A 00 00 x1h x1l 2B 00 00 y1h y1l 2C, DC=0), then pixel data as a second request (DC=1). RGB565, byte order follows the pixel order setting. GET /api/fb readback.
